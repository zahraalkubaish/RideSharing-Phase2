# RideSharing — Phase 2

Java Data Structures | King Saud University | CSC 212

## Overview

A collaborative academic ride-sharing system developed as part of the Data Structures course. The project explores modeling riders, drivers and ride scheduling using custom data structures.

## Project progression

- [Phase 1 — RideSharing System](https://github.com/zahraalkubaish/CSC212_phase1): command-line application using a custom doubly linked list, with rider and driver management, private and shared rides, and scheduling conflict detection.
- Phase 2: ongoing academic development. Final implementation details, team credits and execution instructions will be documented after the project is completed and verified.

## Status

Work in progress — this repository is not presented as a completed release.
